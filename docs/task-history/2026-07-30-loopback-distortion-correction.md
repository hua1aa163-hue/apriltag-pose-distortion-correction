## 首轮技术判断

样例为 27×7 规则点阵；相机图中同时存在透视梯形、反射曲面引入的非线性弯曲和低背景对比度。只进行相机镜头的径向畸变参数修正不足以解决问题，核心应是建立“投影像素 → 相机观察像素”的稠密映射，并据此生成投影端预畸变图。

首轮调研方向包括：

- Gray Code 投影—相机标定；
- OpenCV structured light / projector-camera calibration；
- 基于点阵对应关系的 TPS、分片仿射或稠密网格反向映射；
- 通过重复采集误差形成闭环迭代。

## 首轮调研结果

建议采用“端到端相机—投影稠密映射 + 回环残差修正”，而不是只做相机镜头参数矫正。规则点阵用于初始定位和最终验收，正式标定建议使用约 46 张 Gray Code 图卡逐张投影、拍摄，以建立稠密像素对应关系。

已确认的参考方向：

- MIT 许可的 `procam-calibration`、`graycode-procam-calibration`；
- OpenCV `structured_light`；
- 海康新版 C# SDK 和 GigE 抓图示例；
- 参考工程中的 Windows 桌面壁纸切换实现。
